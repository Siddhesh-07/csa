ServiceNow CSA – Main Topics and Their Uses
============================================

1. ServiceNow Platform --- Used to manage IT services, incidents, requests, and workflows.

2. Navigation & Interface --- Used to navigate the platform, access modules, and find features.

3. Tables & Records --- Used to store data in tables and manage individual records.

4. Lists & Forms --- Lists display multiple records; forms display and edit individual records.

5. Filters & Search --- Used to find specific records based on conditions.

6. Users, Groups & Roles --- Used to manage users, organize teams, and control access.

7. Access Control (ACL) --- Used to control who can read, write, create, or delete data.

8. Applications & Modules --- Used to organize platform features and functionality.

9. Client Scripts --- Used to execute JavaScript in the browser and control form behavior.

10. Business Rules --- Used to execute server-side logic when records are inserted, updated, deleted, or queried.

11. UI Policies --- Used to make fields mandatory, read-only, or visible based on conditions.

12. Notifications --- Used to send emails and alerts when specific events occur.

13. Import Sets & Transform Maps --- Used to import external data and map fields into ServiceNow tables.

14. Update Sets --- Used to transfer configuration changes between ServiceNow instances.

15. Reports & Dashboards --- Used to visualize data, track performance, and monitor activities.

16. Service Catalog --- Used to let users request services, software, hardware, and other items.

17. Knowledge Management --- Used to create and share knowledge articles, guides, and solutions.

18. CMDB & CSDM --- CMDB stores information about Configuration Items; CSDM provides a standard model for organizing service-related data.

19. Flow Designer --- Used to automate tasks and workflows with minimal or no coding.

20. Virtual Agent --- Used to provide automated conversational support through chat.

21. Form Layout & Form Design --- Used to customize the arrangement of fields and sections on forms.

22. Dictionary --- Used to define table fields, field types, default values, and field properties.

23. Reference Fields --- Used to link records from one table to records in another table.

24. Table Inheritance --- Used to create child tables that inherit fields and functionality from parent tables.

25. Task Table --- Used as a parent table for task-based records such as incidents, problems, and changes.

26. Data Policies --- Used to enforce data requirements, such as mandatory and read-only fields, on incoming data.

27. UI Actions --- Used to create buttons, links, and context menu options to perform specific actions.

28. Scheduled Jobs --- Used to execute scripts or tasks automatically at scheduled times.

29. Script Includes --- Used to store reusable server-side JavaScript functions.

30. GlideRecord --- Used to query, retrieve, insert, update, and delete records using server-side scripts.

31. GlideSystem (gs) --- Used to access system information, log messages, and perform server-side utility functions.

32. GlideAjax --- Used to call server-side Script Includes from client-side scripts asynchronously.

33. Events & Event Registry --- Used to register and trigger events for notifications and other automated actions.

34. Data Lookup --- Used to automatically populate field values based on predefined matching conditions.

35. Service Level Agreements (SLAs) --- Used to track and manage response and resolution time commitments.

36. Incident Management --- Used to record, track, and resolve service disruptions.

37. Problem Management --- Used to identify the root causes of incidents and prevent recurring issues.

38. Change Management --- Used to plan, assess, approve, and manage changes to IT services.

39. Request Management --- Used to manage user requests for services and track their fulfilment.

40. Assignment Rules --- Used to automatically assign tasks to appropriate users or groups based on conditions.

41. Data Sources --- Used to define where imported data comes from, such as files or external systems.

42. Scheduled Data Imports --- Used to import data from external sources automatically at scheduled intervals.

43. Notifications & Email Templates --- Used to configure email content and send automated communications.

44. Schema Map --- Used to visualize tables, their relationships, and table inheritance.

45. System Properties --- Used to configure platform behavior through system-wide settings.

46. Delegated Development --- Used to allow authorized developers to work on specific application configurations.

47. Application Scope --- Used to isolate application resources and control access between applications.

48. Plugins --- Used to activate additional ServiceNow features and capabilities.

49. Instance Cloning --- Used to copy data and configuration from one ServiceNow instance to another.

50. ServiceNow Store --- Used to discover and install applications and integrations.

51. Assignment Groups --- Used to organize users into teams and route tasks to the appropriate team.

52. User Criteria --- Used to control which users can access specific Service Catalog items or knowledge content.

53. Catalog Items --- Used to provide individual services or products that users can request from the Service Catalog.

54. Record Producers --- Used to allow users to create records in a table through a simplified Service Catalog form.

55. Order Guides --- Used to allow users to request multiple related Catalog Items together.

56. Catalog Variables --- Used to collect additional information from users when they request a Catalog Item.

57. Knowledge Bases --- Used to organize knowledge articles into different collections based on topics or audiences.

58. Notifications Preferences --- Used to control which notifications users receive and how they receive them.

59. Approval Rules --- Used to determine when a record or request requires approval and who should approve it.

60. Workflows --- Used to automate a sequence of activities, approvals, and tasks for business processes.
IMPORTANT CONCEPTS TO REMEMBER
===============================

Client Script --- Browser-side behavior.

Business Rule --- Server-side logic.

UI Policy --- Controls field visibility, mandatory, and read-only.

ACL --- Controls access and permissions.

Update Set --- Transfers configuration changes between instances.

Transform Map --- Maps imported data to ServiceNow tables.

CMDB --- Stores configuration item information.

Flow Designer --- Automates workflows.
